# Student Mental Health Analysis

## 1. Project Title

Student Mental Health Analysis Using Microsoft Power BI

## 2. Project Overview

This project uses Microsoft Power BI to analyze student mental health data and identify patterns related to anxiety, depression, academic performance, and other factors that may be associated with students' mental well-being. The analysis demonstrates how data can be cleaned, transformed, analyzed, and visualized to support data-driven understanding.

## 3. Problem Statement

Student mental health can affect academic performance, daily activities, and overall well-being. Without proper analysis, it can be difficult to identify patterns in anxiety, depression, and other factors affecting students.

This project addresses this challenge by analyzing student mental health data and presenting the findings through interactive Power BI visualizations.

## 4. Data Source

The project used a student mental health dataset obtained from *Kaggle*, a platform for publicly available datasets and data science resources.

The dataset contains information related to:

- Student demographics
- Academic performance
- Anxiety
- Depression
- Mental health-related factors
- Other student-related characteristics

## 5. Methodology

The project followed these main steps:

1. Imported the student mental health dataset into Microsoft Power BI.
2. Cleaned and prepared the data using Power Query.
3. Transformed data types and prepared the dataset for analysis.
4. Modeled the data for analysis and visualization.
5. Developed DAX calculations for analysis.
6. Analyzed anxiety, depression, academic performance, and other student characteristics.
7. Created interactive Power BI dashboards and visualizations.
8. Interpreted the results and identified useful findings.

### Tools Used

*Microsoft Power BI | Power Query | DAX*

## Dashboard

The interactive Power BI dashboard provides a visual overview of student mental health indicators, including anxiety and depression.

## 6. Key Insights

The analysis produced the following key findings:

- The dataset contained *101 students*.
- Approximately *33.7%* of students were identified with anxiety.
- Approximately *34.7%* of students were identified with depression.
- The dashboard provides an overview of mental health patterns among the students included in the dataset.

## 7. Conclusion / Recommendations

### Conclusion

The analysis demonstrates how Power BI can be used to transform student mental health data into meaningful information. The dashboard provides a clear overview of anxiety, depression, and other student characteristics, helping to identify patterns within the analyzed dataset.

### Recommendations

Based on the findings, institutions should:

- *Monitor student mental health indicators* to identify areas requiring attention.
- *Provide appropriate support and guidance* for students experiencing mental health challenges.
- *Promote awareness of available mental health support services* within educational institutions.
- *Use data-driven monitoring* to better understand changes in student mental health patterns.
- *Conduct further analysis with larger and more diverse datasets* to improve the reliability and generalizability of findings.
